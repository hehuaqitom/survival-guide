# 末日生存手册 · Post-Apocalyptic Survival Guide

> 当文明崩塌，知识就是你最强大的武器。

一个**完全离线**的单文件生存知识库 —— 21 个功能板块、25 份内置速查资料，全部塞进一个 HTML 文件里。

| | |

## 🎯 应用场景

- **家庭应急储备** —— 盘点物资、盯紧保质期、定期做一次检查清单
- **停电停水 / 灾害被困** —— 查净水方案、分配食物、处理伤病
- **户外徒步与露营** —— 离线辨识可食植物、看星图定方向、用摩尔斯发求救信号
- **长途自驾 / 房车生活** —— 房车改装方案、紧急电话、无线电频道
- **应急知识学习** —— 从零开始系统了解生存常识
- **信号中断时** —— 全部内容本地可用，不依赖任何网络
- **灾后长期生活** —— 单机小游戏、琴房、白噪音助眠，都是给情绪留的出口

## 🚀 使用方法

1. 下载 `mori_v2.0.html`
2. 双击，用浏览器打开（推荐 Chrome / Edge / Safari）
3. 完事 —— 手机上建议「添加到主屏幕」，用起来和 App 一样

> 无需联网、无需安装，可以放在 U 盘或随身的任何设备里。
